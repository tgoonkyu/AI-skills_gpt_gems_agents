## ⚙️ Core Planning Philosophy

Where an experiment involves planning or decision-making, the goal is to make the AI behave more like a **practical planning assistant** rather than a simple text generator.

The general philosophy is:

> **Understand → Clarify → Research → Compare → Plan → Validate → Present**

This means an agent should ideally:

1. **Understand the objective**
2. **Identify important constraints**
3. **Ask for missing information when it materially affects the result**
4. **Research current information when required**
5. **Compare realistic alternatives**
6. **Build a practical plan**
7. **Validate the plan against the original constraints**
8. **Present the result in a useful, shareable format**

The experiments in this repository may deliberately vary this approach to see which instruction patterns produce better results.

## 🗂️ Current Experiments

### 🌴 Goa Trip Planner

The first major experiment in this repository is a **Goa Trip Planner**.

It explores how the same planning concept can be implemented as:

- 🧩 AI Skill
- 🤖 AI Agent
- ✨ Gemini Gem
- 💬 Custom GPT

The planner is intended to handle configurable travel requirements rather than relying on a fixed itinerary.

It can be designed around variables such as:

```text
Dates
Travellers / Pax
Destination
Length of stay
Mode of travel
Flights / trains / buses / self-drive / other
Accommodation
Budget
Activities
Itinerary preferences
Special requirements
```

The purpose of the experiment is to determine how much **better structured instructions and planning logic** can improve the final travel-planning experience.
